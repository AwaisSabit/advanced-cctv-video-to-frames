# Changelog

## 1.0.0

- First release: video metadata, frame extraction by interval,
  range, timestamps, scene changes and motion, sharpness and
  quality scoring with clear-frame filtering, digital zoom and
  panning, sharpening, denoising and low-light enhancement,
  timestamp and label overlays, PNG/JPG saving with metadata
  JSON, contact sheets, batch processing and a full command
  line interface.
